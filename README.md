# ConstruStock

Sistema web de gerenciamento de estoque e cotações para lojas de materiais de construção.

O **ConstruStock** é um projeto desenvolvido durante a formação técnica em Desenvolvimento de Sistemas pelo SENAI, com o objetivo de otimizar o controle de produtos, o acompanhamento de estoque e o gerenciamento de cotações com fornecedores.

A aplicação oferece uma interface administrativa para facilitar o gerenciamento das operações e fornecer informações relevantes para a tomada de decisões.

## Funcionalidades

- **Dashboard administrativo:** visualização de indicadores, gráficos e informações gerais do estoque.
- **Gestão de produtos:** cadastro, edição, consulta e gerenciamento de produtos.
- **Controle de estoque:** acompanhamento das quantidades disponíveis, limites mínimos e máximos e identificação de produtos com estoque baixo.
- **Gestão de fornecedores:** organização e consulta de fornecedores.
- **Sistema de cotações:** comparação de preços entre fornecedores e geração de solicitações de cotação.
- **Relatórios:** exportação de informações e relatórios em PDF e Excel.
- **Interface responsiva:** organização das informações em uma interface administrativa.

Os comandos de instalação e inicialização do front-end e da API devem seguir os scripts definidos nos respectivos arquivos `package.json`, localizados na raiz do projeto e na pasta `api/`.

É necessário ter Node.js e npm instalados para executar o projeto localmente.

As instruções específicas de inicialização serão documentadas conforme a configuração do ambiente.
